# خادم العيادة

قاعدة بيانات للمرضى، وقواعد سلامة، ونموذج LM Studio المحلي، ولوحة للطبيب، وتطبيق المريض، كلها من عنوان واحد.

## التشغيل

1. افتح LM Studio، حمّل `qwen/qwen3.6-35b-a3b`، وفعّل الخادم (المنفذ 1234). من الطرفية: `lms server start --port 1234`.
2. من مجلد المشروع:

```bash
node server/server.mjs
```

يتطلب Node 22.13 أو أحدث (قاعدة البيانات SQLite مدمجة فيه، بدون تثبيت).

3. الصفحات:
   - **لوحة الطبيب:** http://127.0.0.1:8787/doctor (الرمز يظهر في الطرفية، وأيضاً في `data/doctor-token.txt`)
   - **تطبيق المريض:** http://127.0.0.1:8787/patient/ (رمز الدخول التجريبي 1234)

## الإعدادات (اختيارية)

| المتغير | الافتراضي |
|---|---|
| `PORT` | `8787` |
| `HOST` | `127.0.0.1` |
| `DATA_DIR` | `server/data` |
| `DOCTOR_TOKEN` | يُولَّد ويُحفظ في `data/doctor-token.txt` |
| `LM_URL` | `http://127.0.0.1:1234/v1` |
| `LM_MODEL` | `qwen/qwen3.6-35b-a3b` |

## كيف يعمل

- **الطبيب** يدخل بيانات كل مريض من لوحة الطبيب: الاسم والعمر والجنس والحساسية والأمراض المزمنة والحمل والأدوية والعلاج وأي تفاصيل. تُحفظ في `data/clinic.db` ويصل إليها الطبيب في أي وقت.
- **المريض** يسأل، فيقرأ الخادم ملفه من قاعدة البيانات **في تلك اللحظة**، ويقرأ آخر رسائل المحادثة، ثم يجيب النموذج حسب حال هذا المريض.
- **إذا لم تكن الحساسية أو الأمراض المزمنة أو الحمل (للنساء) مسجلة**، يسأل المريض أولاً، ثم يجيب على سؤاله الأصلي.
- **السؤال الحرج** يصل للطبيب كتنبيه في لوحة الطبيب، والمريض يُبلَّغ أن الدكتور سيراجعه.
- **رد الطبيب** يكتبه في لوحة الطبيب ويصل للمريض في المحادثة خلال 4 ثوانٍ تقريباً.

## قواعد السلامة (في الكود، لا تعتمد على النموذج)

1. كلمات الطوارئ (نزيف، صعوبة تنفس أو بلع، حرارة...) ترد برسالة ثابتة وتُرسل تنبيهاً فوراً.
2. السؤال عن تغيير أو إيقاف دواء يُحوَّل للطبيب.
3. حساسية البنسلين + سؤال عن الأموكسيسيلين أو المضادات: يُمنع الرد ويُحوَّل للطبيب.
4. النموذج يضع علامة `[يحتاج رأي الطبيب]` عندما يحتاج السؤال قراراً طبياً، فيُرسل تنبيه.
5. الصور تُرسل للطبيب للمراجعة دائماً.

## الملفات

- `server.mjs`: المسارات والمنطق.
- `db.mjs`: قاعدة البيانات.
- `rules.mjs`: قواعد السلامة والنصوص الثابتة.
- `llm.mjs`: تعليمات النموذج وبناء السياق والاتصال بـ LM Studio.
- `seed.mjs`: مرضى تجريبيون، يُضافون إذا كانت القاعدة فارغة.
- `public/doctor.html`: لوحة الطبيب.
- `data/`: قاعدة البيانات والرمز (لا تُرفع إلى Git).

## ملاحظات قبل الاستخدام الحقيقي

- الخادم يعمل على الجهاز نفسه فقط (`127.0.0.1`). وصول المرضى من هواتفهم عبر الإنترنت يحتاج نشراً آمناً بـ HTTPS وتسجيل دخول للمريض، وهذا لم يُنفَّذ بعد.
- صفحة المريض تطلب الرمز 1234 تجريبياً، ولم يُربط بتحقق حقيقي بعد.
- الأرقام الموجودة في `seed.mjs` وهمية (سارة حالة تجريبية). عدّلها أو احذفها من لوحة الطبيب.
